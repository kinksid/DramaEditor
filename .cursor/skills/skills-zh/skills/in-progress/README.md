# 进行中

仍在开发中的技能。它们尚未准备好发布——预计会有粗糙的边缘、破坏性变更和废弃的实验。在它们过渡到稳定桶之前，它们被排除在插件和顶级 README 之外。

- **[review](./review/SKILL.md)** — 沿两个平行轴审查自固定点以来的变更：**标准**（差异是否符合仓库的编码标准？）和**规范**（差异是否忠实地实现了原始问题/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** — 将文章塑造为节奏之旅，选择你自己的冒险风格。选择一个起始节奏，只编写该节奏，然后转向下一个，直到文章达到自然结束。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 问答会话，挖掘你的片段——异质的写作 nuggets——并将它们作为未来文章的原始材料附加到单个文档中。
- **[writing-shape](./writing-shape/SKILL.md)** — 获取原始材料的 markdown 文件，并逐段将其塑造成文章，在每一步论证格式选择。
