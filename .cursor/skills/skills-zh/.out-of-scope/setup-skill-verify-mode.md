# `setup-matt-pocock-skills` 的验证/检查模式

本项目不会为 `setup-matt-pocock-skills` 添加专门的验证/检查模式（或单独的验证技能）。

## 为什么这不在范围内

第二个技能——或 `--verify` 标志——用于检查 `docs/agents/*.md` 工件是否仍然符合种子模板架构，这将重复现有设置技能在对话中已经处理的工作。

预期的工作流程是：**运行 `/setup-matt-pocock-skills` 并告诉它验证你的当前设置。** 该技能由提示驱动，因此维护者可以将其范围限定为验证传递（"不要重写任何内容，只需根据当前种子模板检查我的现有文件并报告偏差"），而无需单独的代码路径。添加标志或同级技能会分割一个已经可以通过自然语言入口点表达的功能的表面区域。

将配置管理保持在单个技能中也避免了当种子模板演进时两个技能相互偏离的维护成本。
